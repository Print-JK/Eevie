# Eevie
A browser extension that functions as an integrated, localized AI agent directly within the browsing experience (initially targeting Firefox). The core focus is seamless voice interaction and multi-model AI capability powered by local resources.

## Using Eevie

- Open the sidebar and use **⚙ Settings** to select an AI model, system voice, and optional local Whisper transcription endpoint.
- Voice replies are on by default. Use **Speak test** in Settings to confirm the selected voice; the sidebar's **🔊 Voice** button mutes or restores replies.
- For speech input, choose **Voice**, press the microphone once to start listening, speak, then press it again to submit. Firefox needs built-in speech recognition or the configured local Whisper endpoint.
- Local media controls run on the active tab: `pause video`, `play`, `mute`, `unmute`, `lower volume`, `set volume to 50%`, and `skip forward 30 seconds`.
